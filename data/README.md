# 상품 데이터 관리 (data/products.json)

이 파일이 상품 정보의 유일한 원본(source of truth)입니다. 화면(`js/main.js`)은 이 파일을 읽어서
자동으로 카테고리/소그룹별로 렌더링하므로, **HTML이나 JS 코드를 건드릴 필요 없이 이 파일만 수정**하면 됩니다.

## 필드 설명

```json
{
  "id": "int-biz",              // 고유 식별자 (영문 소문자-하이픈). 중복되면 안 됨
  "name": "기업 초고속인터넷",      // 화면에 표시될 상품명
  "category": "유선 인터넷",       // 대분류. 상단 필터 버튼과 자동으로 연동됨
  "group": "기업 인터넷",          // (선택) 소분류. 카테고리 선택 시 이 이름으로 소제목이 생김
  "status": "active",           // "active"(판매중) | "legacy"(기존 가입자용, 신규판매 중단)
  "launchDate": "2024-01-01",   // 출시/등록일 (YYYY-MM-DD)
  "description": "...",         // 카드에 표시될 한두 줄 설명
  "price": "상담 문의"            // 요금 표시 문구
}
```

## 신규 상품 추가

배열 마지막(또는 원하는 위치)에 객체를 하나 추가하면 끝입니다.

```json
{
  "id": "new-product-id",
  "name": "신규 상품명",
  "category": "유선 인터넷",
  "group": "전용회선",
  "status": "active",
  "launchDate": "2026-09-03",
  "description": "상품 설명 한두 줄.",
  "price": "상담 문의"
}
```

- `category`를 기존에 없던 값으로 쓰면 필터 버튼이 자동으로 새로 생깁니다.
- `group`을 생략하면 소그룹 구분 없이 카테고리 안에 바로 표시됩니다.

## 상품 삭제 / 단종

- **완전히 안내를 중단**할 상품 → 해당 객체를 배열에서 삭제.
- **신규 판매만 중단**하고 기존 가입자에게는 계속 노출해야 할 상품(기업상품 특성상 흔함)
  → 삭제하지 말고 `"status": "legacy"`로 변경. 화면에 "기존 가입자용" 배지로 흐리게 표시됩니다.

## 요금 추가/수정

각 상품의 `price` 필드 문자열만 바꾸면 됩니다. 지금은 전부 `"상담 문의"`로 되어 있고,
실제 요금이 확정되면 그 값만 교체하면 됩니다 (예: `"price": "월 55,000원 (VAT 별도)"`).

여러 구간 요금(예: 계약기간별/속도별)이 필요해지면 `price`를 문자열 대신 아래처럼 배열로 바꿔도
`main.js`의 최소 수정만으로 확장 가능한 구조입니다 (현재는 문자열 그대로 표시만 함):

```json
"price": [
  { "label": "1년 약정", "value": "월 55,000원" },
  { "label": "3년 약정", "value": "월 45,000원" }
]
```

## 체크리스트

- JSON 문법 오류(콤마 누락 등) 주의 — 수정 후 브라우저에서 `data/products.json`을 직접 열어
  파싱 에러가 없는지 확인하거나, VSCode 등 에디터의 JSON 문법 체크를 활용.
- `id`는 항상 고유해야 함.
